Actúa como un experto desarrollador de integraciones de Meta (WhatsApp Cloud API) y Cloudflare Workers.

Necesito que crees el código para un Cloudflare Worker en JavaScript que funcionará como el Webhook de mi aplicación de WhatsApp. El archivo debe llamarse worker.js (o el nombre estándar para mi repo) y estará ubicado en mi carpeta backend.

Requisitos técnicos del código:

Debe usar la sintaxis moderna de Cloudflare Workers (ES Modules con export default { async fetch(request, env, ctx) { ... } }).

Debe manejar tanto peticiones GET (para la verificación inicial de Meta) como peticiones POST (para recibir los mensajes entrantes).

La ruta que debe escuchar es /webhook (o la ruta raíz /, maneja ambas por seguridad).

El token de verificación estático será: mi_token_secreto_s26

Lógica del método GET (Verificación de Meta):

Extrae los parámetros de la URL: hub.mode, hub.verify_token y hub.challenge.

Si hub.mode es igual a "subscribe" y hub.verify_token coincide con mi token estático, devuelve únicamente el valor de hub.challenge con un status 200 OK.

Si el token no coincide, devuelve un status 403 Forbidden.

Lógica del método POST (Recepción de mensajes):

Lee el cuerpo de la petición en formato JSON.

Imprime el JSON en consola (usando console.log) para poder revisarlo luego en los logs de Cloudflare.

Responde inmediatamente con un status 200 OK (y un texto como "EVENT_RECEIVED") para evitar que Meta reenvíe el mensaje múltiples veces.
